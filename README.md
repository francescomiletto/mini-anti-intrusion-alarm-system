# Mini Anti-Intrusion Alarm System

A compact security alarm prototype designed to detect unauthorized access using digital/analog sensors and alert the user through local feedback.

---

## 🇬🇧 English Description

### Overview
This project is a miniature anti-intrusion security system prototype. It integrates motion/presence detection sensors with a microcontroller unit to monitor a secure area and trigger an alert mechanism upon detecting an unauthorized intrusion.

### Key Features
- **Sensor Integration:** Utilizes proximity/motion sensors (e.g., PIR, ultrasonic, or magnetic contact switches) to monitor the environment.
- **Control Logic:** Microcontroller-based processing unit managing sensor inputs and output states.
- **Alert System:** Features local visual and/or acoustic warnings (such as LEDs and a buzzer) when a breach is detected.
- **Application:** Demonstrates fundamental concepts of home automation, security loops, and embedded logic.

---

## 🇮🇹 Descrizione in Italiano

### Panoramica
Un prototipo di sistema di allarme anti-intrusione in miniatura, progettato per rilevare accessi non autorizzati e segnalare la violazione tramite feedback locale.

### Caratteristiche Principali
- **Integrazione Sensori:** Utilizza sensori di presenza o prossimità (es. PIR, ultrasuoni o contatti magnetici) per il monitoraggio dell'area.
- **Logica di Controllo:** Gestita tramite microcontrollore per l'elaborazione degli ingressi e la gestione degli stati.
- **Sistema di Allarme:** Dotato di segnalatori acustici e/o visivi (come LED e buzzer) per notificare l'intrusione in tempo reale.
- **Finalità:** Un'applicazione pratica di domotica, logica di sicurezza e prototipazione elettronica.
